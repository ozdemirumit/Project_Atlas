# Project Atlas

## Release Process

**Version:** 0.1 Draft  
**Status:** In Progress

## 1. Purpose

This document defines the release process for Atlas.

## 2. Release Goals

- Produce repeatable releases.
- Version platform, APIs, connectors, agents, and documents.
- Provide release notes and upgrade guidance.
- Support enterprise validation and rollback.
- Preserve audit and compliance evidence for releases.

## 3. Versioned Artifacts

- Platform application
- Backend API
- Frontend UI
- MCP connectors
- AI agent prompts and policies
- Workflow definitions
- Database migrations
- Documentation
- Deployment bundles

## 4. Release Requirements

- Changelog
- Known issues
- Upgrade notes
- Rollback notes
- Security notes
- Compatibility matrix
- Validation results

- Which semantic versioning scheme should be used?
