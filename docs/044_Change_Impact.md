# Project Atlas

## Change Impact

**Version:** 0.1 Draft  
**Status:** In Progress

## 1. Purpose

This document defines change impact analysis for Atlas.

## 2. Change Impact Goals

- Estimate affected systems before change.
- Estimate service interruption risk.
- Identify dependencies and blast radius.
- Provide safer change planning.
- Support approval workflows and ITSM integration.

## 3. Analysis Inputs

- Proposed action
- Target component
- Infrastructure graph
- Current health state
- Known dependencies
- Change window
- Historical incidents
- Vendor documentation
- Runbooks

## 4. Output Format

- Proposed change summary
- Affected infrastructure
- Affected services
- Risk level
- Expected duration
- Possible downtime
- Preconditions
- Rollback plan
- Approval requirements
- Recommendation
