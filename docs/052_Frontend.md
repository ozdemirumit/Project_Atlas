# Project Atlas

## Frontend

**Version:** 0.1 Draft  
**Status:** In Progress

## 1. Purpose

This document defines frontend direction for Atlas.

## 2. Frontend Goals

- Provide a chat-centered operations interface.
- Make infrastructure context easy to inspect.
- Present evidence, impact, risk, and recommendations clearly.
- Support approval workflows.
- Support dashboards and reports without becoming only a monitoring UI.

## 3. Primary Views

- Chat workspace
- Infrastructure inventory
- Infrastructure graph
- Connector registry
- Health checks
- Reports
- Approval queue
- Audit viewer
- Administration

## 4. UX Principles

- Prioritize clarity and operational trust.
- Keep evidence inspectable.
- Make risk and approval status obvious.
- Avoid hiding uncertainty.
- Support repeated operational use.
